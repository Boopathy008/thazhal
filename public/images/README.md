## ✅ Tips
- Supported formats: `.jpg`, `.jpeg`, `.webp`, `.png`
- Recommended size: **1200×800px** or larger
- Keep file size under **500 KB** per image for fast loading
- After dropping the files here, tell the AI to "connect the images" and it will wire them up automatically.
