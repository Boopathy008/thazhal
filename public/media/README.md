# Hero video
Place your licensed hero video here as `hero.mp4` (H.264, ~1080p, 10–20 s loop, under ~6 MB, no audio)
and optionally `hero.webm`. Until then the site shows `hero-poster.svg` automatically.
Replace the poster with a still frame (jpg/webp) and update the path in `src/components/Hero.tsx` if you like.
